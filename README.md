Semantic Similarity-based RAG System using Gemini API and ChromaDB

This project is a Retrieval-Augmented Generation (RAG) system designed to improve the accuracy and relevance of LLM-generated responses by leveraging embedding-based document retrieval. Built with Python, it integrates Google’s Gemini API as the language model and ChromaDB as the vector database.

Key Features:
Dense Vector Similarity Retrieval: Utilizes embedding vectors and cosine similarity to retrieve contextually aligned documents.

LLM-Powered Generation: Combines retrieved documents with Gemini API to generate grounded, accurate responses.

Efficient Chunking & Indexing: Implements optimized document segmentation and indexing for scalable storage and lookup.

Modular Design: Built for easy replacement of model, retriever, or evaluation components.

Evaluation Metrics: Includes tools to measure retrieval precision and response relevance.
